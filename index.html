1. Updated System Architecture (HTML/CSS/JS + Python Backend)

Layer Technology What It Does in CurryKrust
Frontend UI HTML5, CSS3, Vanilla JS Renders the project input form, interactive module cards, lock/unlock animations, quiz modals, and persists state via localStorage + REST calls.
Backend API Bridge FastAPI (Python) Serves 2 clean endpoints: POST /api/generate-course and POST /api/evaluate-module with CORS enabled for instant JS fetch() calls.
External APIs Tavily API + YouTube API Fetches real, domain-verified tutorials and documentation based on project name, description, and baseline skill level.
Machine Learning Scikit-Learn (TF-IDF + Cosine) Computes a 0–100% Credibility & Relevance Match Score comparing scraped articles to the user's project description, plus adaptive pacing weight.
Generative AI Google GenAI (Gemini 2.5 Flash) Compiles timed modules (Theory + Immediate Practice + 5-Q Quiz + Mini-Project) in strict JSON and grades user submissions to unlock the next module.

Prompt 1: Generate the Backend (FastAPI + API + ML + Gemini)

Build a complete Python FastAPI backend in a folder called `backend/` for an EdTech hackathon app named "CurryKrust". Create 3 files: `schemas.py`, `ml_engine.py`, and `main.py`. 1. In `schemas.py`, define Pydantic models for: - `CourseRequest`: project_name (str), description (str), hours_per_day (float), deadline_days (int), skill_level (str). - `ResourceLink`: title (str), url (str), ml_relevance_score (float). - `QuizQuestion`: question (str), options (list[str]), correct_index (int), explanation (str). - `ModuleItem`: module_number (int), title (str), estimated_hours (float), theory_summary (str), credible_links (list[ResourceLink]), immediate_practice_prompt (str), quiz (list[QuizQuestion]), final_mini_project (str). - `CourseResponse`: project_name (str), total_hours (float), modules (list[ModuleItem]). 2. In `ml_engine.py`, write a function `fetch_and_score_resources(project_desc, query)` that calls the Tavily Search API (`include_domains=["developer.mozilla.org", "docs.python.org", "geeksforgeeks.org", "freecodecamp.org", "w3schools.com"]`), then uses `scikit-learn` `TfidfVectorizer` and `cosine_similarity` to score how closely each result matches `project_desc` (0-100%). Also include an `adaptive_pacing_score(quiz_score, time_spent)` ML helper. 3. In `main.py`, add FastAPI with CORSMiddleware (`allow_origins=["*"]`) and two endpoints: - `POST /api/generate-course`: Calculates total hours, fetches ML-scored resources, and uses the `google-genai` SDK (`gemini-2.5-flash`) with Structured Outputs (`CourseResponse`) to return 4 completable modules. - `POST /api/evaluate-assessment`: Takes `module_title`, `quiz_score`, and `user_project_submission` (code or text), grades it with Gemini out of 100, and returns `{"passed": bool, "total_score": int, "feedback": str, "next_module_difficulty": str}` (pass threshold >= 80).
